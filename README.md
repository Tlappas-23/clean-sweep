# Clean Sweep

An Oscar-ballot drafting game in the spirit of [82-0](https://www.82-0.com):
a slot machine hands you a film year, you pick a contender for each of six
Academy Award categories, and an awards-season simulation tells you how many
of the 30 stops on the circuit your ballot would have swept.

See `docs/` for the game design, architecture, data pipeline, ML models and
API contract. Full setup instructions follow once the app is assembled.
